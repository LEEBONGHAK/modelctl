# PR #20 — Add an owner-only validated release command

- Merged: 2026-08-03
- Base / head: `main` ← `release/owner-command`
- Merge commit: `69ae28c65d0606d8a7907659dff5c4ac31284d6b`

## English

### Context

The connector-backed merge of PR #19 updated `main`, but it did not emit the workflow event expected to publish the already validated v0.1.0 release. The repository needed an explicit fallback that preserved the full release trust boundary.

### Changes

- Added an owner-only `/release <tag>` pull-request comment workflow.
- Required the referenced pull request to be merged into `main` and resolved its exact merge commit through the GitHub API.
- Verified that the merge commit belongs to `origin/main`.
- Repeated release metadata validation, dependency audit, Ruff, the complete pytest suite, package builds, installed-wheel smoke tests, and checksum generation.
- Granted `contents: write` only to the final publication job.
- Preserved immutable tags and GitHub Releases while keeping PyPI disabled.

### Validation and outcome

Workflow regression tests, the complete release gates, and the cross-platform test matrix passed. PR #20 was squash merged into `main` at commit `69ae28c65d0606d8a7907659dff5c4ac31284d6b`, and v0.1.0 was subsequently tagged at its validated release commit.

## 한국어

### 배경

Connector 기반 PR #19 병합으로 `main`은 갱신됐지만, 이미 검증한 v0.1.0을 게시할 것으로 예상한 workflow 이벤트가 발생하지 않았습니다. 따라서 전체 release 신뢰 경계를 유지하는 명시적 fallback이 필요했습니다.

### 변경 내용

- 소유자만 사용할 수 있는 `/release <tag>` Pull Request 댓글 workflow를 추가했습니다.
- 대상 Pull Request가 `main`에 실제 병합됐는지 확인하고 GitHub API로 정확한 merge commit을 조회했습니다.
- Merge commit이 `origin/main`에 포함되는지 검증했습니다.
- Release metadata 검증, dependency audit, Ruff, 전체 pytest, package build, 설치된 wheel smoke test, checksum 생성을 다시 수행하도록 했습니다.
- 최종 게시 job에만 `contents: write` 권한을 부여했습니다.
- Tag와 GitHub Release 불변성을 유지하고 PyPI 게시를 비활성 상태로 유지했습니다.

### 검증 및 결과

Workflow 회귀 테스트, 전체 release gate, cross-platform test matrix가 통과했습니다. PR #20은 commit `69ae28c65d0606d8a7907659dff5c4ac31284d6b`로 `main`에 squash merge됐으며, 이후 v0.1.0은 검증된 release commit에 tag로 생성됐습니다.
