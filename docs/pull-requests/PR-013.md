## English

### Context

Workspace tests proved that source code worked inside the repository, but they did not prove that publishable artifacts could be built, installed together, and executed outside the checkout.

### Changes

- Added wheel and source-distribution builds for `modelctl`, `modelctl-core`, and `modelctl-sdk`.
- Used `uv build --no-sources` to avoid workspace source overrides in release artifacts.
- Added a `Package` GitHub Actions workflow.
- Installed all built wheels into a fresh Python 3.13 virtual environment.
- Verified installed imports for CLI, core, and SDK packages.
- Verified the installed `modelctl version` and `modelctl --help` commands.
- Uploaded successful distributions as a workflow artifact.
- Changed version output to read installed distribution metadata.
- Added regression tests and release-build documentation.

### Validation and outcome

The package workflow, Ruff, and the three-operating-system test matrix all passed. The repository became capable of producing tested release artifacts, while actual package-index publication and release tagging remained separate follow-up work.

## 한국어

### 배경

Workspace 테스트는 저장소 내부의 source code가 동작함을 증명했지만, 실제 배포물을 빌드하고 저장소 밖의 격리 환경에 함께 설치해 실행할 수 있는지는 보장하지 못했습니다.

### 변경 내용

- `modelctl`, `modelctl-core`, `modelctl-sdk`의 wheel과 source distribution 빌드를 추가했습니다.
- Release artifact가 workspace source override에 의존하지 않도록 `uv build --no-sources`를 사용했습니다.
- `Package` GitHub Actions workflow를 추가했습니다.
- 생성한 모든 wheel을 새로운 Python 3.13 가상환경에 설치했습니다.
- CLI, core, SDK 패키지의 설치된 import를 검증했습니다.
- 설치된 `modelctl version`과 `modelctl --help`를 검증했습니다.
- 성공한 배포물을 workflow artifact로 업로드했습니다.
- 버전 출력이 설치된 distribution metadata를 읽도록 변경했습니다.
- 회귀 테스트와 release build 문서를 추가했습니다.

### 검증 및 결과

Package workflow, Ruff, 세 운영체제 test matrix가 모두 통과했습니다. 테스트된 release artifact를 생성할 수 있게 됐으며 실제 package index 게시와 release tag 생성은 다음 작업으로 분리했습니다.
