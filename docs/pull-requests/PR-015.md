## English

### Context

The repository could build and install coordinated distributions, but it lacked an enforceable connection between package versions, release tags, and published GitHub artifacts.

### Changes

- Added coordinated-version validation for `modelctl`, `modelctl-core`, and `modelctl-sdk`.
- Required release tags to equal the package version with a `v` prefix.
- Added release dry runs for pull requests and manual validation.
- Required tagged commits to be contained in `refac`.
- Built and installed release artifacts in a fresh Python 3.13 environment.
- Generated `SHA256SUMS` and temporary workflow artifacts.
- Added GitHub Release creation for validated tags.
- Added bilingual release instructions and regression tests.

### Validation and outcome

The Release dry run, package smoke workflow, Ruff, and the Linux/macOS/Windows test matrix passed. No tag or package publication was performed by the PR itself.

A later security hardening PR removed the dormant PyPI job, isolated untrusted manual tag input, pinned Actions by commit SHA, and made existing releases immutable.

## 한국어

### 배경

저장소는 통합 배포물을 빌드하고 설치할 수 있었지만 package version, release tag, 게시된 GitHub artifact 사이의 관계를 강제하는 절차가 없었습니다.

### 변경 내용

- `modelctl`, `modelctl-core`, `modelctl-sdk` 통합 version 검증을 추가했습니다.
- Release tag가 package version 앞에 `v`를 붙인 값과 같도록 강제했습니다.
- Pull Request 및 수동 검증을 위한 release dry run을 추가했습니다.
- Tag 대상 commit이 `refac`에 포함되도록 검증했습니다.
- 새로운 Python 3.13 환경에서 release artifact를 빌드하고 설치했습니다.
- `SHA256SUMS`와 임시 workflow artifact를 생성했습니다.
- 검증된 tag에 대한 GitHub Release 생성을 추가했습니다.
- 영문·한국어 release 안내와 회귀 테스트를 추가했습니다.

### 검증 및 결과

Release dry run, package smoke workflow, Ruff, Linux·macOS·Windows test matrix가 통과했습니다. PR 자체에서는 tag 생성이나 package 게시를 수행하지 않았습니다.

후속 보안 하드닝 PR에서 사용하지 않는 PyPI job 제거, 신뢰하지 않는 수동 tag 입력 격리, Action commit SHA 고정, 기존 release 불변 정책을 적용했습니다.
