# PR #33 — Remove stale audit exclusion and enforce clean ready releases

- Pull request: https://github.com/LEEBONGHAK/modelctl/pull/33
- Status: Open (validated)
- Base / head: `main` ← `security/remove-stale-audit-ignore`

## English

### Context

PR #30 upgraded the locked dependency to patched `cryptography 50.0.0`, and PR #31 promoted v0.2.0 readiness to `main`. A guarded publication run then showed that the obsolete issue #22 advisory remained in `[tool.uv.audit].ignore`.

The audit found no vulnerability, but it emitted a warning that the ignored advisory no longer matched the project. A ready release must not retain either active or stale audit exclusions.

### Changes

- Removed the obsolete audit ignore block from workspace `pyproject.toml`.
- Added release validation that rejects non-empty audit ignore lists when the manifest status is `ready`.
- Added a regression test for the clean-audit policy.
- Updated English and Korean completion documents from 137 to 138 tests.
- Recorded the failed-safe PR #32 publication finding and remaining publication steps.

### Validation and outcome

- Release metadata validation passed with status `ready`.
- `uv audit --locked` reported no known vulnerabilities and no ignored-advisory warning.
- Ruff passed.
- All 138 tests passed on Ubuntu, macOS, and Windows with Python 3.13.
- All package builds, isolated installed-wheel smoke tests, checksums, and release dry-run gates passed.

This PR must merge before publication. The final tag must target its resulting exact `main` merge commit.

## 한국어

### 배경

PR #30에서 잠긴 dependency를 패치된 `cryptography 50.0.0`으로 올렸고 PR #31에서 v0.2.0 readiness를 `main`에 승격했습니다. 이후 guarded publication 실행에서 issue #22용 advisory가 `[tool.uv.audit].ignore`에 남아 있음을 확인했습니다.

Audit는 취약점을 찾지 않았지만 무시한 advisory가 프로젝트와 더 이상 일치하지 않는다는 경고를 출력했습니다. Ready release는 활성 또는 오래된 audit 예외를 유지하면 안 됩니다.

- Workspace `pyproject.toml`에서 오래된 audit ignore block을 제거했습니다.
- Manifest status가 `ready`일 때 비어 있지 않은 audit ignore 목록을 거부하는 release validation을 추가했습니다.
- Clean-audit 정책 회귀 테스트를 추가했습니다.
- 영문·한국어 완료 문서의 테스트 수를 137개에서 138개로 갱신했습니다.
- 안전하게 실패한 PR #32 게시 결과와 남은 게시 단계를 기록했습니다.

### 검증 및 결과

- Status `ready`로 release metadata 검증이 통과했습니다.
- `uv audit --locked`가 알려진 취약점과 ignored-advisory 경고 없이 통과했습니다.
- Ruff가 통과했습니다.
- Python 3.13 기반 Ubuntu·macOS·Windows에서 전체 138개 테스트가 통과했습니다.
