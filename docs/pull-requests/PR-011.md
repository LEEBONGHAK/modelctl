# PR #11 — Add non-interactive provider and model selection

## English

### Context

`modelctl use` required interactive input, which prevented deterministic use in shell scripts and CI. The interactive path also referenced a provider-scoped repository query that had not been implemented.

### Changes

- Added `modelctl use --provider <id> --model <id>`.
- Added short options `-p` and `-m`.
- Required provider and model options to be supplied together.
- Validated providers against the provider registry.
- Validated models against the synchronized local catalog.
- Returned exit code `2` and an actionable sync command for invalid direct selections.
- Preserved the existing interactive selector.
- Restored provider-scoped model repository lookup methods.
- Added CLI, service, and SQLite repository tests.

### Validation and outcome

Scripts and CI gained deterministic configuration without changing the persisted configuration format:

```bash
modelctl use -p openrouter -m anthropic/claude-sonnet-4
```

## 한국어

### 배경

`modelctl use`는 대화형 입력만 지원해 shell script와 CI에서 결정적으로 사용할 수 없었습니다. 또한 대화형 경로가 호출하는 provider 범위 저장소 조회 메서드가 구현되지 않은 문제도 발견됐습니다.

### 변경 내용

- `modelctl use --provider <id> --model <id>`를 추가했습니다.
- 단축 옵션 `-p`, `-m`을 추가했습니다.
- provider와 model 옵션을 반드시 함께 사용하도록 검증했습니다.
- provider registry를 기준으로 provider를 검증했습니다.
- 동기화된 로컬 catalog를 기준으로 model을 검증했습니다.
- 잘못된 직접 선택에는 종료 코드 `2`와 sync 안내를 반환했습니다.
- 기존 대화형 선택 흐름을 유지했습니다.
- provider 범위 모델 저장소 조회 메서드를 복구했습니다.
- CLI, service, SQLite repository 테스트를 추가했습니다.

### 검증 및 결과

저장 설정 형식은 변경하지 않으면서 script와 CI에서 결정적인 설정이 가능해졌습니다.

```bash
modelctl use -p openrouter -m anthropic/claude-sonnet-4
```
