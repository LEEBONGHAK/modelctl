## English

### Context

The repository had a working package and release path, but credential fallback, protected local files, authentication wiring, release inputs, and third-party workflow dependencies required a focused security review before the first development release. Two obsolete placeholders had also been approved for removal, and a complete Korean README was requested.

### Changes

- Removed the duplicate placeholder `doctor()` command and unused `ProfileService` stub.
- Added a complete Korean README with language navigation.
- Made the operating-system keyring the default credential store.
- Required explicit opt-in before writing unencrypted fallback credentials.
- Added atomic private-file writes, POSIX `0700`/`0600` permissions, and symbolic-link rejection.
- Unified authentication, diagnostics, and model synchronization on one credential service.
- Repaired model synchronization constructor and credential conversion regressions.
- Hardened OpenRouter credential validation, response handling, timeouts, and HTTP-client lifecycle.
- Pinned external GitHub Actions to immutable commit SHAs.
- Isolated and validated untrusted release-tag input.
- Removed the PyPI publishing job and OIDC write permission.
- Added locked dependency auditing, security tests, `SECURITY.md`, and bilingual release documentation.

### Validation and outcome

Ruff, `uv audit --locked`, package smoke validation, release dry-run validation, and the complete Ubuntu, macOS, and Windows test matrix passed. The security review found no shell execution, dynamic evaluation, unsafe deserialization, or TLS-verification bypass in the reviewed source. PR #16 established the security baseline used for v0.1.0 readiness.

## 한국어

저장소에는 동작하는 패키징 및 릴리스 경로가 있었지만 첫 개발 버전 전에 credential fallback, 보호 대상 로컬 파일, 인증 연결, release 입력, 외부 workflow dependency를 집중적으로 보안 검토할 필요가 있었습니다. 승인된 두 placeholder 제거와 완전한 한국어 README 추가도 함께 요청됐습니다.

- 중복 placeholder `doctor()` 명령과 사용되지 않는 `ProfileService` stub을 제거했습니다.
- 언어 전환 링크가 포함된 완전한 한국어 README를 추가했습니다.

- 암호화되지 않은 fallback credential 저장에 명시적 opt-in을 요구했습니다.

- 인증, 진단, 모델 동기화를 하나의 credential service로 통합했습니다.
- 모델 동기화 생성자 및 credential 변환 회귀를 수정했습니다.
- OpenRouter credential 검증, 응답 처리, timeout, HTTP client lifecycle을 강화했습니다.

- PyPI 게시 job과 OIDC write 권한을 제거했습니다.

### 검증 및 결과

Ruff, `uv audit --locked`, package smoke 검증, release dry-run, Ubuntu·macOS·Windows 전체 test matrix가 통과했습니다. 검토한 source에서는 shell 실행, 동적 평가, 위험한 역직렬화, TLS 검증 우회 경로를 발견하지 못했습니다. PR #16은 v0.1.0 완료 판정에 사용하는 보안 기준선을 마련했습니다.
