## English

### Context

The initial launcher path could invoke Claude Code but did not yet provide a complete native-command experience. Users needed model forwarding, arbitrary Claude arguments, and a useful error when the executable was absent.

### Changes

- Forwarded arguments after `modelctl run` to the selected launcher.
- Constructed Claude Code commands as `claude --model <model> <args...>`.
- Added actionable missing-CLI guidance.
- Updated the Typer argument declaration to satisfy Ruff without changing behavior.
- Added command-construction and missing-executable tests.

### Validation and outcome

The following flows became supported:

```bash
modelctl run
modelctl run --continue
modelctl run --verbose
```

This established the first complete launcher implementation and a pattern later reused by Gemini CLI, Codex CLI, and Aider.

## 한국어

### 배경

초기 launcher 경로는 Claude Code를 호출할 수 있었지만 네이티브 CLI를 충분히 활용하기에는 부족했습니다. 선택한 모델 전달, 임의의 Claude 인자 전달, 실행 파일 누락 시 이해하기 쉬운 안내가 필요했습니다.

### 변경 내용

- `modelctl run` 뒤의 인자를 선택된 launcher로 전달했습니다.
- Claude Code 명령을 `claude --model <model> <args...>` 형식으로 구성했습니다.
- Claude CLI가 없을 때 실행 가능한 설치 안내를 추가했습니다.
- 동작 변경 없이 Typer 인자 선언을 Ruff 기준에 맞게 수정했습니다.
- 명령 생성과 실행 파일 누락에 대한 테스트를 추가했습니다.

### 검증 및 결과

다음 실행 흐름을 사용할 수 있게 됐습니다.

```bash
modelctl run
modelctl run --continue
modelctl run --verbose
```

최초의 완성된 launcher 구현이 되었으며 이후 Gemini CLI, Codex CLI, Aider 연동의 기준 패턴으로 사용됐습니다.
