## English

### Context

Named profiles established the first v0.3.0 user workflow. The next step was to define a public launcher extension boundary before allowing installed packages to participate in runtime discovery.

### Implemented changes

- Defined launcher plugin contract version `1.0` in `modelctl-sdk`.
- Published immutable `LaunchRequest`, explicit `LauncherCapabilities`, validated `LauncherMetadata`, and the structural `LauncherPlugin` protocol.
- Added stable plugin and launcher ID validation.
- Added contract-major compatibility validation.
- Moved the public launcher value types into the SDK so external plugins do not depend on core internals.
- Made built-in launchers satisfy the same public structural contract while preserving runtime behavior.
- Kept discovery, entry-point loading, provider plugins, and automatic installation out of scope.

### Validation

CI, package builds, the complete cross-platform suite, and release metadata dry-run passed before merge.

### Architectural outcome

The dependency direction is now `modelctl-core -> modelctl-sdk` for launcher contracts. External launcher packages can target the SDK rather than importing core implementation details.

## 한국어

### 배경

이름 있는 profile로 v0.3.0의 첫 사용자 workflow를 만든 뒤, 설치된 package를 runtime에 참여시키기 전에 공개 launcher 확장 경계를 먼저 정의해야 했습니다.

### 구현 변경 사항

- `modelctl-sdk`에 launcher plugin contract version `1.0`을 정의했습니다.
- 불변 `LaunchRequest`, 명시적 `LauncherCapabilities`, 검증된 `LauncherMetadata`, 구조적 `LauncherPlugin` protocol을 공개했습니다.
- 안정적인 plugin/launcher ID 검증을 추가했습니다.
- Contract major version 기반 호환성 검증을 추가했습니다.
- 외부 plugin이 core 내부 구현에 의존하지 않도록 공개 launcher value type을 SDK로 이동했습니다.
- 기존 built-in launcher가 runtime 동작을 유지하면서 동일한 공개 구조 계약을 충족하도록 변경했습니다.
- Discovery, entry-point loading, provider plugin, 자동 설치는 범위에서 제외했습니다.

### 검증

병합 전 CI, package build, 전체 cross-platform 테스트, release metadata dry-run이 모두 통과했습니다.

### 아키텍처 결과

Launcher contract의 의존 방향이 `modelctl-core -> modelctl-sdk`로 정리되었습니다. 외부 launcher package는 core 내부 구현 대신 SDK만 대상으로 개발할 수 있습니다.
