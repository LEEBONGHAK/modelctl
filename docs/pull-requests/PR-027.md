## English

### Context

The v0.2.0 capability, strict-policy, and remediation workflows were proven primarily with OpenRouter and Aider. A native provider integration was required to validate the same contracts when provider selection resolves directly to a native coding-agent launcher.

Anthropic was selected first because Claude Code was already implemented and declares Anthropic as its native provider.

### Changes

- Added `AnthropicProvider` to the provider registry.
- Added a bounded Anthropic Models API client for `GET /v1/models`.
- Added fixed `x-api-key` and `anthropic-version: 2023-06-01` request headers.
- Added cursor pagination with a page-size limit of 1,000, repeated-cursor detection, and a maximum-page guard.
- Rejected malformed model responses and invalid pagination metadata explicitly.
- Mapped Anthropic model IDs, display names, maximum input tokens, image-input capability, and thinking capability to `UniversalModel`.
- Added official `ANTHROPIC_API_KEY` environment-variable support while preserving `MODELCTL_ANTHROPIC` precedence.
- Reused the existing Claude Code launcher for native recommendation, strict compatibility, and remediation.
- Added regression tests for API headers, pagination, response validation, mapping, provider discovery, environment resolution, model synchronization, and launcher decisions.
- Added bilingual provider documentation and updated the PR engineering history.

### Security and scope

The client uses a fixed HTTPS endpoint, disables redirects, and applies bounded connect and total timeouts. Pagination is bounded and rejects repeated cursors.

The Anthropic credential managed by modelctl is used for model-catalog synchronization. Claude Code continues to manage its own supported authentication methods. Stored credentials are not copied into launcher subprocess environments automatically.

### Validation and outcome

Dependency audit, Ruff, 121 tests on Ubuntu/macOS/Windows with Python 3.13, package builds, installed-wheel smoke tests, release metadata validation, and checksum generation all passed before merge.

## 한국어

### 배경

v0.2.0의 capability, strict policy, remediation 흐름은 주로 OpenRouter와 Aider 조합으로 검증했습니다. Provider 선택이 native coding-agent launcher로 직접 연결되는 경우에도 같은 계약이 동작하는지 확인하려면 native provider 연동이 필요했습니다.

Claude Code가 이미 구현되어 있고 Anthropic을 native provider로 선언하므로 첫 native provider 기능 단위로 Anthropic을 선택했습니다.

### 변경 내용

- Provider registry에 `AnthropicProvider`를 추가했습니다.
- `GET /v1/models`를 사용하는 제한된 Anthropic Models API client를 추가했습니다.
- `x-api-key`와 `anthropic-version: 2023-06-01` header를 고정했습니다.
- 페이지 크기 1,000개, 반복 cursor 탐지, 최대 페이지 제한을 포함하는 cursor pagination을 추가했습니다.
- 잘못된 모델 응답과 pagination metadata를 명시적으로 거부합니다.
- Anthropic 모델 ID, 표시 이름, 최대 입력 token, 이미지 입력 capability, thinking capability를 `UniversalModel`에 매핑합니다.
- `MODELCTL_ANTHROPIC` 우선순위를 유지하면서 공식 `ANTHROPIC_API_KEY` 환경변수를 지원합니다.
- 기존 Claude Code launcher를 native 추천, strict 호환성, remediation에 재사용합니다.
- API header, pagination, 응답 검증, mapper, provider discovery, 환경변수 조회, 모델 동기화, launcher 판단을 회귀 테스트로 검증합니다.
- 영문·한국어 provider 문서와 PR 개발 이력을 추가했습니다.

### 보안과 범위

Client는 고정 HTTPS endpoint를 사용하고 redirect를 비활성화하며 connect·전체 timeout을 제한합니다. Pagination은 최대 페이지 수를 제한하고 반복 cursor를 거부합니다.

modelctl이 관리하는 Anthropic credential은 모델 catalog 동기화에 사용합니다. Claude Code는 자체 지원 인증 방식을 계속 사용합니다. 저장된 credential은 launcher subprocess 환경에 자동 복사하지 않습니다.
