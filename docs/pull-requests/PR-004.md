## English

### Context

After Claude Code execution worked, the next goal was to prove the launcher abstraction with a second coding-agent CLI and repair configuration commands that no longer matched the dictionary-based configuration format.

### Changes

- Added and registered the Gemini CLI launcher.
- Constructed commands as `gemini --model <model> <args...>`.
- Added installation guidance for a missing Gemini executable.
- Aligned `ConfigService` with `ConfigManager`'s dictionary data.
- Added configuration updates for provider, model, and launcher.
- Supported `modelctl config set provider|model|launcher <value>`.
- Added launcher and configuration regression tests.

### Validation and outcome

Gemini could be selected and invoked with native arguments, while configuration changes became persistent and usable by the runtime. The launcher interface remained intentionally small.

## 한국어

### 배경

Claude Code 실행이 동작한 뒤 두 번째 코딩 에이전트 CLI를 통해 launcher 추상화가 실제로 확장 가능한지 검증할 필요가 있었습니다. 동시에 기존 설정 명령이 dictionary 기반 설정 형식과 맞지 않는 문제도 해결해야 했습니다.

### 변경 내용

- Gemini CLI launcher를 추가하고 registry에 등록했습니다.
- 명령을 `gemini --model <model> <args...>` 형식으로 구성했습니다.
- Gemini 실행 파일이 없을 때 설치 안내를 제공했습니다.
- `ConfigService`를 `ConfigManager`의 dictionary 데이터 형식에 맞췄습니다.
- provider, model, launcher 설정 갱신 기능을 추가했습니다.
- `modelctl config set provider|model|launcher <value>`를 지원했습니다.
- launcher와 설정 회귀 테스트를 추가했습니다.

### 검증 및 결과

Gemini를 선택해 네이티브 인자와 함께 실행할 수 있게 됐고, 설정 변경이 런타임에서 사용할 수 있도록 영속화됐습니다. launcher 인터페이스는 기능 우선 원칙에 따라 작게 유지했습니다.
