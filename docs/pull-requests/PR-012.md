## English

### Context

The CLI targeted all major desktop operating systems, but CI only exercised Ubuntu and duplicated pytest across two workflows. Cross-platform path handling, SQLite behavior, console rendering, and command execution needed real hosted-runner coverage.

### Changes

- Kept the `CI` workflow focused on Ruff validation on Ubuntu.
- Expanded the `Test` workflow to Ubuntu, macOS, and Windows.
- Pinned workflow execution to Python 3.13.
- Used the committed uv lockfile on every platform.
- Disabled matrix fail-fast so every operating system reports independently.
- Updated README and progress documentation with the validation matrix.

### Validation and outcome

The complete pytest suite passed on:

```text
ubuntu-latest / Python 3.13
macos-latest / Python 3.13
windows-latest / Python 3.13
```

This converted cross-platform support from an assumption into a continuously checked property.

## 한국어

### 배경

CLI는 주요 데스크톱 운영체제를 모두 대상으로 했지만 CI는 Ubuntu만 검사했고 두 workflow가 pytest를 중복 실행했습니다. 운영체제별 경로, SQLite, console 출력, 명령 실행을 실제 hosted runner에서 검증할 필요가 있었습니다.

### 변경 내용

- `CI` workflow는 Ubuntu Ruff 검증에 집중하도록 정리했습니다.
- `Test` workflow를 Ubuntu, macOS, Windows로 확장했습니다.
- Workflow Python 버전을 3.13으로 고정했습니다.
- 모든 플랫폼에서 커밋된 uv lockfile을 사용했습니다.
- 한 운영체제가 실패해도 전체 결과를 볼 수 있도록 matrix fail-fast를 비활성화했습니다.
- README와 진행 문서에 검증 matrix를 반영했습니다.

### 검증 및 결과

전체 pytest suite가 다음 환경에서 통과했습니다.

```text
ubuntu-latest / Python 3.13
macos-latest / Python 3.13
windows-latest / Python 3.13
```

Cross-platform 지원이 추정이 아니라 지속적으로 검사되는 품질 속성이 됐습니다.
