## English

### Context

Aider was the first launcher that required provider context in addition to a model ID. OpenRouter model names also had to be translated to Aider's `openrouter/<provider>/<model>` format.

### Changes

- Added and registered the Aider launcher.
- Extended launcher execution to receive an optional provider ID.
- Forwarded configured provider context through `LauncherService`.
- Added automatic OpenRouter model-prefix normalization.
- Preserved model names unchanged for other providers.
- Added actionable Aider installation guidance.
- Added launcher, registry, and provider-forwarding tests.

### Validation and outcome

An OpenRouter selection such as `anthropic/claude-sonnet-4` is executed as:

```bash
aider --model openrouter/anthropic/claude-sonnet-4
```

This was the first integration to expose a proven need for provider-aware launcher execution without triggering a larger refactor.

## 한국어

### 배경

Aider는 모델 ID뿐 아니라 provider 정보까지 필요한 최초의 launcher였습니다. OpenRouter 모델 이름도 Aider가 요구하는 `openrouter/<provider>/<model>` 형식으로 변환해야 했습니다.

### 변경 내용

- Aider launcher를 추가하고 registry에 등록했습니다.
- launcher 실행 인터페이스가 선택적으로 provider ID를 받도록 확장했습니다.
- `LauncherService`가 설정된 provider 정보를 전달하도록 수정했습니다.
- OpenRouter 모델 prefix를 자동으로 정규화했습니다.
- 다른 provider의 모델 이름은 변경하지 않고 유지했습니다.
- Aider 설치 안내를 추가했습니다.
- launcher, registry, provider 전달 테스트를 추가했습니다.

### 검증 및 결과

`anthropic/claude-sonnet-4`와 같은 OpenRouter 선택은 다음 명령으로 실행됩니다.

```bash
aider --model openrouter/anthropic/claude-sonnet-4
```

대규모 리팩터링 없이도 provider-aware 실행이 실제 요구사항임을 최초로 확인한 연동이었습니다.
