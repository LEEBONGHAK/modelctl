Issue #22 tracked `GHSA-g6cj-pr64-35w5` / `CVE-2026-69247`, affecting `cryptography >=44.0.0,<50.0.0`. The project lock selected 49.0.0 after upstream had released patched version 50.0.0 on 2026-07-31.

This security update removed the vulnerable locked version before the v0.2.0 manifest was marked ready.

- Refreshed `uv.lock` with `uv lock --upgrade-package cryptography`.
- Upgraded `cryptography` from 49.0.0 to 50.0.0.
- Replaced locked source and wheel artifact metadata with the 50.0.0 release.
- Finalized the merged PR #29 engineering record.
- Added bilingual PR #30 history and updated the v0.2.0 changelog and completion plan.

### Validation and outcome

- Locked installation selected `cryptography 50.0.0`.
- `uv audit --locked` passed without an advisory exclusion.
- Ruff and native-provider contract suites passed.
- All 137 tests passed on Ubuntu, macOS, and Windows with Python 3.13.
- Package builds, isolated installed-wheel smoke tests, release dry-run, and checksums passed.
- PR #30 merged into `refac` as `1fb85812b5aca2232ac2fb479e35f38d837bb229`.
- Issue #22 was closed as completed with validation evidence.
