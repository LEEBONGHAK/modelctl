# PR #30 — Upgrade cryptography to the patched release

- Pull request: https://github.com/LEEBONGHAK/modelctl/pull/30
- Status: Open
- Base / head: `refac` ← `security/cryptography-50`

## English

### Context

Issue #22 tracked a temporary response to `GHSA-g6cj-pr64-35w5` / `CVE-2026-69247`, which affects `cryptography >=44.0.0,<50.0.0`. The project lock still selected 49.0.0 while upstream had released the patched 50.0.0 version on 2026-07-31.

This security update is a required v0.2.0 readiness step. It removes the vulnerable locked version before the release manifest can be marked ready.

### Changes

- Refreshed `uv.lock` with `uv lock --upgrade-package cryptography`.
- Upgraded `cryptography` from 49.0.0 to 50.0.0.
- Replaced the source-distribution and wheel URLs, hashes, sizes, and upload metadata with the 50.0.0 release artifacts.
- Finalized the merged PR #29 engineering record.
- Added the PR #30 bilingual engineering record and history-index entry.
- Updated v0.2.0 progress and changelog documentation.

### Security outcome

The patched dependency contains the upstream PKCS#7 EnvelopedData decryption fix. No dependency-audit exclusion is retained. Issue #22 can be closed after this pull request is merged.

### Validation and outcome

- Locked dependency installation selected `cryptography 50.0.0`.
- `uv audit --locked` passed without an advisory exclusion.
- Ruff passed.
- Anthropic, Google, and OpenAI provider contract tests passed.
- The complete 137-test suite passed on Ubuntu, macOS, and Windows with Python 3.13.
- All package builds and installed-wheel smoke tests passed.
- The coordinated v0.2.0 release dry-run and checksum generation passed.
