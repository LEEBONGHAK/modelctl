## English

### Context

PR #23 proved command-scoped strict compatibility behavior across supported platforms. Users who repeatedly run modelctl in automation or safety-sensitive environments need to select that behavior once as a durable default, while existing installations must remain warning-only unless they explicitly opt in.

### Changes

- Added `modelctl config set compatibility-policy <warn|strict>`.
- Defaulted configurations without a policy to `warn` for backward compatibility.
- Made `modelctl run` resolve the persisted policy when no run-specific override is supplied.
- Preserved `--strict-compatibility` and added `--warn-compatibility` as one-run overrides.
- Rejected unsupported policy values during configuration and rejected invalid persisted values during execution.
- Added ConfigService, config CLI, LauncherService, and run CLI regression tests.
- Updated English and Korean usage, changelog, project progress, and PR engineering history.

### Validation and outcome

Dependency audit, Ruff, 101 tests on Ubuntu, macOS, and Windows, all wheel/source-distribution builds, installed-wheel smoke tests, release metadata validation, and checksum generation passed. The pull request was merged into `refac`, making persisted compatibility behavior the third completed v0.2.0 increment.

## 한국어

### 배경

PR #23에서 command-scoped strict compatibility 동작을 지원 플랫폼 전체에서 검증했습니다. 자동화나 안전이 중요한 환경에서 modelctl을 반복 실행하는 사용자는 이 동작을 한 번 설정해 기본값으로 유지할 수 있어야 하며, 기존 설치는 명시적으로 선택하지 않는 한 계속 경고 방식으로 동작해야 합니다.

### 변경 내용

- `modelctl config set compatibility-policy <warn|strict>`를 추가했습니다.
- 정책이 없는 기존 설정은 하위 호환성을 위해 `warn`을 기본값으로 사용합니다.
- 실행별 override가 없으면 `modelctl run`이 저장된 정책을 사용하도록 변경했습니다.
- `--strict-compatibility`를 유지하고 1회성 override인 `--warn-compatibility`를 추가했습니다.
- 설정 시 지원하지 않는 정책을 거부하고 실행 시 잘못 저장된 정책도 명시적으로 오류 처리합니다.
- ConfigService, config CLI, LauncherService, run CLI 회귀 테스트를 추가했습니다.
- 영문·한국어 사용법, changelog, 프로젝트 진행 문서, PR 개발 이력을 갱신했습니다.
